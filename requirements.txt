# ShieldNet - runtime requirements
# ============================================================================
#   cd shieldnet && pip install -r requirements.txt
#
# Equivalent to `pip install -e ".[all]"`, kept as a file because Colab, Binder and
# most CI images expect one. Version floors, not pins: pins rot, and every floor here
# marks a real API this code depends on rather than "the version I happened to have".
#
# The `-e .` below is not decoration. Without it pip installs these dependencies and
# not ShieldNet itself, so `import shieldnet` and the `shieldnet` command are both
# missing and the failure looks like a broken install rather than an incomplete one.
# pip resolves that `.` against your working directory, not against this file, which is
# why the invocation above cds first.
# ============================================================================

-e .
